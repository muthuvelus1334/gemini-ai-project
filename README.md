# gemini-ai-project
Gemini AI Studio is an interactive, full-stack AI web application developed using Python, Streamlit, and the Google Gemini Generative AI SDK.

The application serves as an all-in-one AI workspace featuring four core capabilities:

🤖 Conversational ChatBot: An interactive multi-turn conversational agent with persistent chat history.
📷 Snap Narrate (Image Captioning): A multimodal vision tool that accepts uploaded images (PNG/JPG) and generates descriptive captions and visual analysis using Gemini's multimodal capabilities.
🔡 Text Embeddings Generator: A utility leveraging high-dimensional embedding models (gemini-embedding-001) to convert natural language into dense vector representations suitable for semantic search and retrieval tasks.
❓ Ask Me Anything (Q&A Engine): A zero-shot prompt-engineering interface for immediate answers, creative generation, and technical problem-solving.
